# Cursor Rules Directory

This directory contains all cursor rules files for the Sudoku Clash project.

## Files

- `general-rules.md` - General coding and project guidelines
- `typescript-rules.md` - TypeScript-specific rules and best practices
- `nextjs-rules.md` - Next.js framework rules and conventions
- `nodejs-rules.md` - Node.js and backend rules
- `solana-wallet-rules.md` - Solana wallet integration rules
- `solana-kit-rules.md` - Solana Kit integration rules
- `seeker-integration-rules.md` - Solana Seeker dApp store integration rules
- `twa-deployment-rules.md` - Trusted Web Activity (TWA) deployment rules

## Usage

These files are automatically referenced by `.cursorrules` in the project root. Cursor AI will use these rules when assisting with code generation and suggestions.
